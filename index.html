ออกใบกำกับภาษี
💡 ระบบจะดึง Invoice ทั้งหมดของเดือนที่เลือก (รวม Special Invoice) และจัดกลุ่มตามสาขาลูกค้าอัตโนมัติ
ใบที่สร้างครั้งแรกเป็น ร่าง — เลขที่ใบกำกับภาษีจะถูกใช้เมื่อกด “ออกใบกำกับภาษี” เท่านั้น และ Invoice ที่อยู่ในใบที่ออกแล้วจะถูกล็อกไม่ให้แก้/ลบ
🔥
เชื่อมต่อ Firebase Database
⚪ ยังไม่ได้เชื่อมต่อ
💡 ใส่ค่าจาก Firebase Console → Project Settings → Your apps → Config
ข้อมูลจะ sync อัตโนมัติทุกเครื่องที่เปิด — ไม่มี pause ไม่มีค่าใช้จ่ายสำหรับการใช้งานทั่วไป
🔐 เข้าสู่ระบบ (Firebase Authentication)
⚪ ยังไม่ได้เข้าสู่ระบบ
วิธีตั้งค่าให้ปลอดภัย (ทำครั้งเดียวใน Firebase Console)
  1. Authentication → Sign-in method → เปิด Email/Password
  2. Authentication → Users → Add user (บัญชีของผู้ใช้งานแต่ละคน)
  3. Firestore Database → Rules → วางกฎด้านล่างแล้วกด Publish
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
